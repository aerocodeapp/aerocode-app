> **Enter a code. Get your event.**

AeroCode replaces holding your phone up at events. Instead of filming, you enjoy the moment — then enter an event code like `WHM-KAMPALA-001` and instantly get all your photos, videos, audio & announcements in HD.

---

## 🎯 The Problem

Globally, at church services, weddings, conferences, graduation ceremonies, stadium matches and many other occasions people holds their phone up to film, to get photos, highlights and content videos to play on Tiktok, YouTube etc.  They miss the moment, block others, and end up with shaky, low-quality videos.

YouTube / Facebook Live only lets you *watch* — you don't get anything to keep.

## 💡 The Solution

One drone / aerial camera films the event professionally. Everyone else puts their phones down. After the event, they enter a code and get everything.

**YouTube lets you watch the service. AeroCode lets you take the service home with you.**

## ✨ How It Works

1.  **Organizer Creates Event**
    Pastor / MC / Organizer creates an event in the app and gets a unique code + QR.
    Example: `WHM-KAMPALA-001` for Worship Harvest Ministries, Kampala.

2.  **Drone / Camera Captures**
    Drone films outside + aerial views. Fixed high camera films inside for safety.
    No flying over heads.

3.  **Attendee Enters Code**
    Attendee opens AeroCode, types the code or scans QR.
    No account needed for viewing.

4.  **Download Everything**
    - Full HD Photos & Videos
    - Sermon / Talk Audio (MP3)
    - Clips: Choir Only, Sermon Only, Testimonies
    - Announcements (PDF)
    - "Find Me" - Photos you appear in

## 🏟️ Stadium Mode

AeroCode scales from 200 people in church to 40,000 people in a stadium.

**Example:** Uganda Cranes at Mandela National Stadium, Namboole
**Code:** `CRANES-001` or `ST-NAMBOOLE-001`

### How Stadium Mode Works
1. **One Code Per Event + One Code Per Section**
   - Main Code: `CRANES-001` - for everyone
   - VIP Code: `CRANES-VIP` - VIP photos only
   - Section Code: `CRANES-B12` - for Section B, Row 12 fans

2. **Drones Fly Around, Not Over Crowd**
   - Drones film from outside stadium + pitch edge + high above
   - Roof cameras film inside for safety (UCAA compliant)
   - No drone flies over 40,000 people

3. **Offline-First**
   - Stadium network is bad. Fans get code in stadium, download at home on WiFi.
   - Codes work for 7 days after event.

4. **Find Me By Seat**
   - Fan enters Seat: `Section B, Row 12, Seat 45`
   - AeroCode shows photos of that section + crowd celebration

## 🔐 Security

- Codes expire after 7 days
- One code = limited downloads (e.g. 200 for one service, 40,000 for stadium)
- View-Only mode for sensitive conferences (no download)
- Watermark option for photos
- All data owned by Global AeroCode Technologies Limited.
